# v2.1.0: University of Oregon DuckWeb adapter + no-school guard

Status: done, pending Web Store upload (2026-10-10)

## Why

A friend testing at the University of Oregon saw no ratings. UO's class schedule
is DuckWeb (`duckweb.uoregon.edu/duckweb/hwskdhnt.*`), a custom Banner 8 PL/SQL
app. Its URL matches none of the manifest patterns, so the content script never
ran, and its instructor cells read `Lastname F` (no `(Primary)` marker), so the
Banner parser would not have matched anyway.

Separately, `background.js` falls back to USF's school ID when no school is
selected. A student at another school who skips the picker gets USF professors
matched by last name and initial, which is confidently wrong data.
